# スキル: 数値チェック (numeric-check)

## 役割

レポート内のすべての数値・統計・パーセンテージの根拠を確認し、信頼性を判定する。

## チェック手順

### ステップ 1: 数値の洗い出し

レポートから以下を全て抽出する：
- 市場規模（○○億円など）
- 成長率・伸び率（○%増など）
- 比率・割合（市場シェア○%など）
- 技術仕様値（成分含有率○%など）
- 統計数値（件数・棟数・企業数など）

### ステップ 2: 根拠の確認

各数値について：

```
数値: （数値の内容）
出典: （資料名・URLまたは「不明」）
調査年: （○年○月または「不明」）
サンプル数: （記載ありの場合のみ）
判定: 根拠あり / 根拠不明 / 要確認
```

### ステップ 3: 判定基準

| 判定 | 条件 | レポートでの扱い |
|------|------|-----------------|
| 根拠あり | 一次資料で確認済み、出典明記 | そのまま使用可 |
| 要確認 | 出典あるが一次資料未確認 | 【要確認】付きで使用 |
| 根拠不明 | 出典なし・SNS・まとめサイト | **使用禁止** |

### ステップ 4: 修正指示

根拠不明の数値が見つかった場合：
1. その数値をレポートから除外する
2. 「【根拠不明・除外】〇〇という数値は根拠未確認のため掲載を保留」と記載する
3. 「次に調べるべきこと」セクションに追加する

## よくある落とし穴

- 「業界関係者によると」は根拠なしとして扱う
- 複数サイトで同じ数値が流通していても、一次資料に戻れなければ根拠不明
- 古い統計（5年以上前）は「○年時点の数値」と明記する
