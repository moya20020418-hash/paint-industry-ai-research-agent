# スキル: 資料監査 (source-audit)

## 役割

調査で使用した情報源の信頼性・根拠の有無を検証する。

## 監査基準

### 信頼度ランク

| ランク | 種類 | 例 |
|--------|------|----|
| A（高） | 一次資料 | 企業公式サイト、有報、政府統計、公式PDF |
| B（中） | 二次資料 | 業界誌、学術論文、信頼性の高い調査会社 |
| C（低） | 三次資料以下 | まとめサイト、ブログ、SNS引用 |
| 禁止 | 使用不可 | SNS投稿、掲示板、出所不明 |

### 監査チェック項目

各情報源について以下を確認する：

- [ ] URLまたは資料名が明記されているか
- [ ] 調査・発行年月が確認できるか
- [ ] 発行機関・著者が信頼できるか
- [ ] 数値に調査方法・サンプル数の記載があるか
- [ ] 一次資料にさかのぼれるか（二次資料の場合）

## 監査レポートの記入方法

```
| 情報 | 出典 | ランク | 監査結果 |
|------|------|--------|----------|
| ○○の市場規模は△△円 | 経産省○年統計 | A | 合格 |
| □□の普及率は△%  | 出所不明のブログ | 禁止 | 除外 |
```

## 判定基準

- ランクCの情報は【要確認】として残す
- ランク禁止の情報はレポートから除外する
- 根拠が確認できない数値は「【根拠不明・使用禁止】」と付記する
