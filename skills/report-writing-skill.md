# スキル: レポート執筆 (report-writing)

## 役割

調査結果を読みやすいMarkdownレポートにまとめ、品質を確保する。

## 執筆原則

1. **正確性優先** - 不確かな情報より空白を選ぶ
2. **根拠の透明性** - 読者が検証できるよう出典を明記する
3. **層の分離** - 事実・推測・示唆を混在させない
4. **断定表現の排除** - 「可能性がある」「考えられる」を使う

## レポート構造

```
# Daily Market Research Report
## 1. 調査テーマ       ← 何を調査したか
## 2. 今日の重要トピック ← 今日のハイライト（3〜5点）
## 3. 入力情報の要約   ← 元データの概要
## 4. 事実として確認できること ← 一次資料確認済みのみ
## 5. 推測・仮説       ← 【推測】タグ必須
## 6. 市場・企業への示唆 ← 【示唆】タグ必須
## 7. 数値・根拠の確認  ← 全数値に出典
## 8. リスク・不確実性  ← 情報の限界を明示
## 9. 次に調べるべきこと ← 未解決のアクションリスト
## 10. QAチェック     ← 提出前の確認リスト
```

## 文体ガイド

- 体言止めより述語で締める（「〜がある」「〜と考えられる」）
- 受動態より能動態を使う
- 専門用語は初出時に説明を添える
- 箇条書きは3〜7項目以内にまとめる

## 禁止表現

「絶対」「保証」「必ず」「最適」「万能」「問題ありません」「確実に」

## QAチェックの実施

`templates.py` のセクション10を必ず使用し、提出前にすべての項目をチェックする。
