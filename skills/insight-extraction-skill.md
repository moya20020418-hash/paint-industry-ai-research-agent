# スキル: 示唆抽出 (insight-extraction)

## 役割

事実と推測をもとに、ビジネス・市場・戦略上の示唆を導き出す。

## 三層構造の維持

示唆抽出では常に以下の3層を厳密に分離する：

| 層 | 定義 | 表記 |
|----|------|------|
| 事実 | 一次資料で確認済みの情報 | （表記なし or 【事実】） |
| 推測 | 事実から論理的に導出した仮説 | 【推測】 |
| 示唆 | 推測・事実をもとにしたアクション提案 | 【示唆】 |

## 示唆の導出プロセス

### ステップ 1: 事実の整理

セクション4（事実として確認できること）から出発する。

### ステップ 2: 推測の形成

事実から「もし〜ならば、〜の可能性がある」という論理ステップで推測を形成する。

禁止表現：
- 「〜は確実です」
- 「〜は間違いありません」
- 「必ず〜になります」

許可表現：
- 「〜の可能性がある」
- 「〜と考えられる」
- 「〜の傾向がみられる」

### ステップ 3: 示唆の形成

推測を前提に、企業・投資・マーケティング等の観点から「検討に値する行動」を提案する。

```
【示唆】
根拠：（参照した事実・推測）
示唆内容：（〜を検討する余地がある / 〜が有効かもしれない）
前提条件：（この示唆が成立するための条件）
確認が必要な事項：（示唆を実行する前に確認すべきこと）
```

## NG例・OK例

| NG | OK |
|----|-----|
| 「この市場は成長します」 | 「インフラ補修需要は拡大傾向にある可能性がある（【推測】）」 |
| 「この製品が最適です」 | 「〜の用途においては有力な選択肢になりうる（【示唆】）」 |
| 「他社より優れています」 | 「公式資料上、亜鉛含有率は〜%と高い数値が確認できる（【事実】）」 |
