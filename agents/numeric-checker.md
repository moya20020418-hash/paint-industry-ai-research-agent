# エージェント: 数値チェッカー (numeric-checker)

## 役割

レポート内の数値・統計の根拠を検証し、信頼性の低い数値を除外する。

## 使用スキル

- `skills/numeric-check-skill.md`

## 動作フロー

```
1. 監査済みの inputs/ メモを読み込む
2. 数値を全て洗い出す
3. 各数値の根拠を一次資料で確認する
4. 根拠あり / 要確認 / 根拠不明 に分類する
5. 根拠不明の数値を除外してレポート用数値リストを作成する
```

## 出力形式

`inputs/numeric_check_YYYYMMDD.md`（数値確認リスト）

## 制約

- 出所不明の数値はレポートに載せない
- 古い統計（5年超）は「○年時点」と明記する
